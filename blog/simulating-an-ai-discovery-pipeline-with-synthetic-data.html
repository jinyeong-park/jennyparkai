Why Build the Data From Scratch

The interesting failures don't show up in clean data

Most portfolio datasets are too well-behaved to teach anything about GEO measurement. The actual hard problems in this domain — stripped referrers, non-deterministic model outputs, a ranking penalty that fires without warning — only show up when you deliberately model the noise. So instead of downloading a Kaggle set and running a clean aggregation, I designed five tables meant to reproduce those specific failure modes, in DuckDB, sized to run comfortably on a laptop.

Three Deliberate Distortions

What I injected on purpose, and why

Referrer stripping. referrer_domain is set to null for roughly half of AI-sourced sessions, while landing_page_path still carries distinct, feature-specific URLs. That gap is the entire reason a custom GA4 channel rule is necessary rather than cosmetic — the data can't be recovered from referrer alone.

Conversion asymmetry. AI-sourced sessions carry roughly 4.4× the conversion rate of organic, with ~68% longer session durations, matched to the empirical ratios in the research this project is grounded in. Without that asymmetry baked in, any downstream LTV analysis would just be measuring noise.

A stability regression. An Android app update on Day 15 spikes anr_rate above the 0.47% demotion threshold, with a correlated drop in Play Store search impressions a few days later. This is the one that makes the Android Vitals story concrete instead of theoretical — you can watch the demotion happen in the data, not just read about the threshold.

What This Exercise Actually Tests

Building the dataset is a design problem before it's a SQL problem

The generation script itself is the less interesting part. The real work is upstream of it: deciding which relationships in the real system are worth reproducing at all, and which distortions are load-bearing for the questions the dashboard is supposed to answer. A synthetic dataset that's too clean teaches nothing about attribution repair, algorithmic demotion, or non-deterministic measurement — the three problems that actually define this domain in 2026.
